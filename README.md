# 🫀 Калькулятор кардиометаболического риска (CMDS)

Кроссплатформенное приложение для расчёта стадии кардиометаболического риска по шкале **Cardiometabolic Disease Staging (CMDS)**. Предназначено для использования как врачами, так и пациентами.

## 📋 О проекте

Приложение автоматизирует оценку кардиометаболического риска на основе клинических параметров пациента. По результатам ввода данных рассчитывается стадия CMDS (0–4) и отображаются выявленные факторы риска.

### Стадии CMDS

| Стадия | Описание |
|---|---|
| **0** | Отсутствие факторов кардиометаболического риска |
| **1** | Низкий риск (10-летний риск СД 2 типа ↑ в 1,75 раза) |
| **2** | Средний риск (10-летний риск СД 2 типа ↑ в 4,6 раза) |
| **3** | Высокий риск (10-летний риск СД 2 типа ↑ в 11 раз) |
| **4** | Очень высокий риск (10-летний риск ССЗ ↑ в 16,3 раза) |

## 🎯 Функциональность

- ✅ Расчёт стадии CMDS на основе 18 клинических параметров
- ✅ Визуализация факторов риска (✅/❌ индикаторы)
- ✅ Валидация вводимых данных (целые числа, дробные числа, обязательные поля)

## 🏗️ Архитектура

Проект построен по принципам **Clean Architecture** с разделением на слои:
```
src/
├── domain/              # Бизнес-логика (не зависит от UI)
│   ├── models.py        # Датаклассы PatientInput, CMDSResult
│   └── evaluator.py     # CMDSEvaluator — расчёт стадии
├── presentation/        # UI-слой (Flet)
│   ├── calc_view.py     # Форма ввода данных
│   └── result_view.py   # Отображение результатов
└── main.py              # Точка входа
```

### Ключевые принципы

- **Разделение ответственности**: доменная логика изолирована от UI
- **Иммутабельность**: `@dataclass(frozen=True)` для входных данных и результатов
- **Типизация**: полная аннотация типов
- **Валидация**: проверка данных на уровне UI и доменной логики

## 🔬 Медицинские критерии

Приложение основано на клинических руководствах.

### Абдоминальное ожирение

| Пол | Окружность талии | Соотношение талия/бёдра |
|---|---|---|
| Мужчины | ≥ 94 см | > 0,9 |
| Женщины | ≥ 80 см | > 0,85 |

### Прочие критерии

| Показатель | Критерий |
|---|---|
| Повышенное АД | ≥ 130/85 мм рт. ст. |
| Гипертриглицеридемия | ТГ ≥ 1,7 ммоль/л |
| Снижение ХС-ЛПВП (мужчины) | < 1,0 ммоль/л |
| Снижение ХС-ЛПВП (женщины) | < 1,2 ммоль/л |

### Предиабет (хотя бы один критерий)

| Показатель | Диапазон |
|---|---|
| Гликемия натощак | 6,1–6,9 ммоль/л |
| Гликемия через 2 ч после ПГТТ | 7,8–11,0 ммоль/л |
| HbA1c | 6,0–6,4% |
